ProjectFlow for OpenProject – Gizlilik Politikası

Son güncelleme: Haziran 2026

ProjectFlow for OpenProject ("uygulama"), OpenProject sunucunuza bağlanan bir mobil istemcidir. Uygulama ücretsiz indirilir; Pro sürümü tek seferlik uygulama içi satın alma ile açılır.

1. Toplanan veriler

Uygulama yalnızca sizin girdiğiniz ve cihazınızda saklanan verileri kullanır:

  • OpenProject instance adresi (URL) ve API anahtarı: Sunucuyla kimlik doğrulama için; cihazın güvenli depolamasında tutulur.
  • Tercihler: Aktif proje, tema, dil, bildirim ayarları.
  • Pro satın alma durumu: Yalnızca cihazda ve Google Play hesabınızla eşleşecek şekilde.
  • Çökme/teşhis (Sentry): Uygulama çökerse anonim teknik hata/çökme verisi gönderilebilir. Kişisel veri içermez.

2. Verilerin kullanımı ve paylaşımı

  • Instance URL ve API anahtarınız yalnızca sizin seçtiğiniz OpenProject sunucusuyla iletişim için kullanılır.
  • Veriler reklamcılarla veya üçüncü taraflarla satılmaz/paylaşılmaz (çökme teşhisi için Sentry hariç, yalnızca anonim teknik veri).
  • Pro ödemesi Google Play tarafından işlenir; uygulama ödeme bilgisi saklamaz.

3. Hesap ve veri silme

Uygulama kendi sunucusunda ayrı bir hesap oluşturmaz; mevcut OpenProject hesabınızla bağlanırsınız. Verilerinizi kaldırmak için:

  • Uygulama içinden: "Çıkış yap" → cihazda saklanan instance URL, API anahtarı ve tercihler silinir.
  • Tam kaldırma: Uygulamayı cihazdan kaldırın → tüm yerel veriler silinir.
  • Erişimi iptal: OpenProject hesabınızda Hesabım → API erişimi bölümünden ilgili API anahtarını silin.
  • Silme talebi: Her türlü veri/hesap silme talebi için mehmetgedik60@gmail.com adresine yazabilirsiniz.

Not: Uygulama verileri yalnızca cihazınızda tutulduğundan, geliştiricinin sunucusunda silinecek ayrı bir kaydınız yoktur. Proje verileriniz OpenProject sunucunuzda kalır ve oranın politikasına tabidir.

4. Güvenlik

API anahtarı ve instance URL'i cihazın güvenli depolama alanında tutulur. Sunucuyla iletişim HTTPS üzerinden yapılır.

5. İletişim

Sorularınız için: mehmetgedik60@gmail.com

ProjectFlow for OpenProject – Privacy Policy

Last updated: June 2026

ProjectFlow for OpenProject ("the app") is a mobile client that connects to your OpenProject server. The app is free; the Pro version is unlocked via a one-time in-app purchase.

1. Data we use

The app only uses data you enter, stored on your device:

  • OpenProject instance URL and API key: for authenticating with your server; kept in the device's secure storage.
  • Preferences: active project, theme, language, notification settings.
  • Pro purchase status: on device only, tied to your Google Play account.
  • Crash/diagnostics (Sentry): anonymous technical crash data may be sent if the app crashes. No personal data.

2. Use and sharing

  • Your instance URL and API key are used only to communicate with the OpenProject server you choose.
  • Data is not sold or shared with advertisers or third parties (except anonymous crash diagnostics via Sentry).
  • Pro payment is processed by Google Play; the app does not store payment details.

3. Account & data deletion

The app does not create a separate account on its own server; you connect with your existing OpenProject account. To remove your data:

  • In-app: "Log out" → the stored instance URL, API key and preferences are deleted from the device.
  • Full removal: uninstall the app → all local data is removed.
  • Revoke access: delete the relevant API token in your OpenProject account (My account → API access).
  • Deletion requests: for any data/account deletion request, email mehmetgedik60@gmail.com.

Note: because app data is stored only on your device, there is no separate record on the developer's servers to delete. Your project data remains on your OpenProject server under its own policy.

4. Security

The API key and instance URL are kept in the device's secure storage. Communication with the server uses HTTPS.

5. Contact

Questions: mehmetgedik60@gmail.com
